## 請低調分享

這裡是 SakuraCat 的官方網址發布頁。

我們懇請大家不要在中國大陸平台公開討論 SakuraCat，也不要在微博、論壇留言區、影片留言區、小紅書、規模較大的 QQ 群、微信群等公開區域發布我們的網址。

我們不希望擴大使用者規模，大家自己低調使用就好。這樣做是為了保護小店的網址不被封鎖，也是在保護您在中國大陸平台的帳號安全與人身安全。

如果您確實需要分享給朋友，建議只透過私訊、一對一聊天等方式傳送連結。
